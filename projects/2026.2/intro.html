Introdução

Projeto Final 2026.2​

O Projeto final tem os seguintes critérios de avaliação (Percentagem da nota):

  1. Conter um dispositivo de entrada e saída(Teclado, botão, sensor, LCD, OLED...) (10%);
  2. Utilizar um periférico dedicado ou rotina de interrupção (ADC, PWM, DMA, Timer...) (10%);
  3. Utilizar MQTT via CubeMonitor (10%);
  4. Utilizar SQL via CubeMonitor (SQLite) (10%);
  5. Ser feito em bancada, protótipo operacional (30%);
  6. Documentação no GitHub (15%);
  7. Video de apresentação (15%); Ex: https://youtu.be/th4r7HzCY8c

Data limite de entrega: 07/12/2026

A partir dos requisitos a equipe tem liberdade para usar tantos componentes e técnicas quanto achar necessário.

Documente o projeto em um repositório no GitHub e elabore um video breve de apresentação;

VS Code deve ser a IDE de uso!

Somente projetos realizados no VS Code serão aceitos!

O código deve compilar!

O código deve compilar! E possuir um release funcional no GitHub.

Crie um fluxograma do projeto!

Fluxograma com meirmaid, utilize o editor e dê uma olhada na documentação;
